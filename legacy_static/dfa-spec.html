FORMAL COMPUTATION THEORY

Deterministic Finite Automaton (DFA) Specification

Mathematical formulation, state transition matrix & interactive online automaton simulator.

Formal 5-Tuple Definition: M = (Q, Σ, δ, q0, F)

1. Set of States (Q)
Q = { S0, S1, S2, S3, S4, S5, S6 }
  • S0: Order Placed (Initial state)
  • S1: Order Confirmed
  • S2: Processing
  • S3: Shipped
  • S4: Out for Delivery
  • S5: Delivered (Accepting / Terminal)
  • S6: Cancelled (Accepting / Terminal)
2. Input Alphabet (Σ)
Σ = { CONFIRM, CANCEL, START_PROCESSING, SHIP, OUT_FOR_DELIVERY, DELIVER }

Events triggered by customer actions or administrative logistics dispatch operations.

3. Initial State (q0) & Final States (F)
• q0 = S0 (Order Placed)
• F = { S5, S6 } (Delivered & Cancelled are terminal absorbing states)

State Transition Function: δ : Q × Σ → Q
